# Result tables

This directory holds no result tables. CSV files that earlier revisions
carried were exported from private research repositories that used vendor data. The
redistribution rights for that data are not recorded, so the files were removed from the
repository and from its history pending confirmation by the owner. The charts, figures and
`docs/data.json` built from them were removed for the same reason.

Results are regenerated by running the included scripts against your own data source. See the
Results section of the top-level README for the commands.

`scripts/build_chart_data.py` reads CSV tables from this directory and writes `docs/data.json`;
`scripts/svgchart.py` turns that file into SVG charts. Both fail until the tables exist. The
exporters that produced the original tables are not part of this repository, so the tables
must be produced by your own tooling with the column names the script reads.
